**메커니즘**:
- 질문의 키워드("CT·MRI·PET", "자연분만", "6세 미만", "건강검진")가 표·Q&A 문단에 **원형 그대로 등장**
- BM25 형태소 토크나이저(Kiwi)가 이 키워드를 매칭 → **정답 근거 청크 순위를 상위로 견인**
- RRF 가 Dense 와 BM25 결과를 결합하여 더 강한 신호 제공
- Gemini 가 보수적 판단을 깨고 실제 답 생성

→ **Failure Case A 의 "Advanced 가 Basic 구원" 시나리오** 확증

## 🔴 주요 역설: q09 (hard/2026 추나요법) 악화

| | Basic | Hybrid |
|---|---|---|
| answer_correctness | **0.98** | **0.03** |
| faithfulness | 0.00 | 0.00 |
| response | "2026년 … 본인부담률은 **80%**" (정답) | "정보를 찾을 수 없습니다" |

**원인 추정 (BM25 양날의 검)**:
- "추나요법", "디스크", "협착증" 등 키워드가 **여러 년도 PDF 에 동일한 표** 로 반복 존재
- BM25 가 다수의 년도 청크를 상위로 견인 → 검색 결과에 2020·2021·2022·2023·2024·2025·2026 추나 표가 혼재
- Gemini 가 "2026년" 을 특정 못하고 혼동 → 보수적으로 "정보 없음" 선택
- Dense 단독이었던 Basic 은 임베딩 유사도로 "2026" 시그널을 더 강하게 잡아 정답 추출했음

**시사점**:
- BM25 는 **키워드가 독특한 문항에는 강력** (q02/q03/q08/q10)
- **같은 키워드가 여러 년도에 반복되는 경우** 오히려 혼동 유발 (q09)
- → **Pre-filter (metadata 버전)** 가 년도 기준으로 corpus 를 좁히면 해결될지가 핵심 관찰 포인트
- → **Rerank (rerank 버전)** 가 질의-문서 cross-encoder 로 다시 정렬하면 개선될지도 관찰

## 기타 관찰

### 가설 H2 (Basic/Advanced 차이 가장 큰 메트릭) 검증
- 가설: "Context Precision 이 가장 크게 개선, 그 다음 Answer Correctness"
- 실제: Faithfulness +0.225 > Relevancy +0.200 > **Precision +0.101** > Correctness +0.061
- → **가설 수정 필요**: BM25 추가만으로는 Precision 보다 **Faithfulness 개선이 더 큼**. 이유는 "정보 없음" 4건이 faithfulness 0→1 로 급등했기 때문.

### easy 난이도의 q04 악화 (-0.40)
- q04: 2023 의료급여의뢰서 7일 질문
- Basic: 정답 100%; Hybrid: 60% 로 떨어짐
- 원인 조사 필요 (아마 BM25 가 다른 "일" 관련 조항을 상위로 올려 답변 희석)

### cross-year 는 대체로 동등
- q15 (장기 비교 2018+2026) 만 개선 (+0.26)
- q12~q14 는 거의 동등 → BM25 만으론 년도 구분 못함 (예상대로)

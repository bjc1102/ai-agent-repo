## 🔴 핵심 발견 2: Ragas 역설 케이스

| 증상 | 예시 |
|---|---|
| **Faith 높음 / Cor 낮음** | q15 (장기비교 2018+2026): Faith=0.71 인데 Rel=0.00, Cor=0.37 → 답변 자체는 컨텍스트 기반인데 질문과의 관련성이 낮음 |
| **Prec 1.00 / Cor 극저** | q10 (hard/2024): Prec=1.00, 근거도 찾음 → 포기 ("정보 없음") |
| **Faith 0 / Cor 높음** | q09 (hard/2026 추나요법): Faith=0.00 인데 Cor=0.98 → 답변이 표 형태 컨텍스트에서 추출한 수치인데 Ragas 가 "직접 인용" 판단 못함 (Ragas 한계) |

**q09 의 Faith=0 → Cor=0.98 역설이 특히 의미 있음**:
- 정답: "80%"
- 답변도 "80%" 맞음
- Ragas Faithfulness 는 LLM 답변을 각 claim 으로 쪼개서 retrieved_contexts 에 grounded 인지 판단 — 표(markdown) 형태에서 "단순추나·특수추나 > 디스크 외 > 1종 80%" 조합 추론이 직접 근거 매칭에 실패
- → **Ragas 기본 메트릭이 표 기반 답변을 과소평가** 할 수 있음 (TASK.md 힌트 "Ragas 가 놓치는 실패 유형" 해당)

## 기술 메모

- **평가용 LLM**: `"LLM returned 1 generations instead of requested 3"` 경고 여러 번 → Answer Relevancy 가 3번 샘플링을 원하는데 GPT-4o-mini 가 1번만 반환. 점수 노이즈 있음. 필요 시 GPT-4o 로 재시도 가능.
- **NaN 발생**: Context Precision 2건 NaN (q04, q06). 이유 조사 필요.
- **TimeoutError 2건** 발생했으나 최종 결과엔 영향 없음 (재시도됨).

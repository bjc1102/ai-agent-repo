# 11주차 과제 제출

[11주차 과제 링크](https://github.com/DChanHong/baseball-agent/blob/main/SUBMIT.md)

이번 과제에서는 KBO 직관 가이드 Agent가 사용자 요청과 세션 정보를 바탕으로 요청 의도, 필요한 Tool과 실행 순서, 추가 질문 필요 여부를 일관된 JSON 형식으로 판단하도록 Fine-tuning 데이터셋을 준비했습니다. 일정·구장·날씨 조회, 좌석 추천, 예매 및 이동 안내뿐 아니라 복합 요청, 일반 대화, 지원 범위 밖 요청까지 다양한 상황을 포함했습니다.

데이터셋은 직접 작성하고 검수한 합성 데이터로 구성했으며, 세션 정보를 활용한 후속 요청과 필수 정보가 부족한 엣지케이스도 반영했습니다. 모든 Assistant 응답의 JSON 파싱과 Tool 실행 순서를 확인했습니다.
